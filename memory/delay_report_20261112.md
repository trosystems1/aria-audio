# 2026-11-12 配信遅延レポートと改善計画

## 遅延の概要

- **配信日**: 2026-11-12（水）
- **予定公開**: 7:00 JST
- **実際の公開**: 8:00 JST頃（1時間遅延）
- **原因**: n8nワークフロー開始が7:00 JST → 口パク（TTS lip-sync）生成に38.6分 → 動画完成が8:00頃

## 根本原因

### n8nスケジュール（主因）
- 旧スケジュール: `0 7 * * 1-6`（JST 7:00に開始）
- 口パク生成: 238秒の音声 → 約38.6分の処理
- 結果: YouTube公開が7:40〜8:10になる
- GitHub Actionsのスケジュール遅延（GitHub社内キュー）は今回の原因ではない

## 実施した改善（2026-11-12）

### 1. スケジュール変更（Task 1）
- **変更前**: `0 7 * * 1-6`（JST 7:00）
- **変更後**: `50 5 * * 1-6`（JST 5:50）
- 目的: 口パク処理の40分を考慮し、7:00公開に間に合わせる

### 2. YouTube予約投稿（Task 2）
- **変更前**: `privacyStatus: "public"` （即時公開）
- **変更後**: `privacyStatus: "private"` + `publishAt: UTC 22:00`（JST 7:00に自動公開）
- 目的: n8nワークフロー完了時刻に関わらず、必ず7:00に公開される

### 3. パッチB実装（Task 3）

#### Build_Thumb_Text ノード
- **タイトル形式変更**: 個別株が主役の日は `【日本語社名 決算】+9%｜フック｜日付` の形式に
  - 旧: `【米国株 速報】NVIDIA +9%｜AI株の今後は？｜11/12`
  - 新: `【エヌビディア 決算】+9%｜AI株の今後は？｜11/12`
  - YouTube検索「エヌビディア 決算」に引っかかりやすくなる
- **概要欄冒頭**: 結論＋数字で始まる形式に変更
  - 旧: `【毎朝7時更新】11月12日｜フック`
  - 新: `【毎朝7時更新】11月12日\nエヌビディア（決算）+9%。フック`

#### Upload a video ノード（タグ強化）
- 主役の日本語名（例: エヌビディア）をタグに追加
- 主役のティッカー（例: NVDA）をタグに追加
- 決算動画には「決算」タグを追加

#### Append_Thumbnail_Tier_Prompt ノード（Claude指示強化）
追加したルール:
- **冒頭15秒ルール**: 最初の15秒で主役名・数字・結論を言い切る
- **銘柄バランスルール**: テック/AI偏重防止（最大2銘柄まで）
- **YouTube SEOルール**: タイトル・概要欄・タグの書き方ガイドライン
- **YouTube推薦アルゴリズム対策**: ログインなし新規ブラウザのレコメンドに拾われる施策
