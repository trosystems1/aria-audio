# 動画公開遅延分析と改善計画 (2026-11-12)

## 原因分析

### 遅延の根本原因
- ワークフロー開始時刻: JST 7:00 (旧スケジュール)
- リップシンク処理時間: 約38.6分
- 結果: JST 7:38〜7:50頃にYouTubeアップロード完了
- 目標公開時刻: JST 7:00 → 大幅遅延

### 処理時間の内訳（推定）
1. データ取得・AI生成 (Grok/Claude): 約5〜8分
2. 音声合成 (TTS): 約3〜5分
3. Shotstack動画生成: 約10〜15分
4. リップシンク処理 (SadTalker/D-ID等): 約15〜20分
5. YouTube アップロード: 約2〜3分
6. 合計: 約35〜51分

## 適用済み改善策

### 1. スケジュール前倒し
- 変更前: `0 7 * * 1-6` (JST 7:00 開始)
- 変更後: `50 20 * * 0-5` (UTC 20:50 = JST 5:50 開始)
- 効果: 処理完了がJST 6:30〜6:50頃になり、JST 7:00公開に間に合う

### 2. YouTube スケジュール公開
- アップロード時: `privacyStatus: "private"` + `publishAt: UTC 22:00`
- UTC 22:00 = JST 翌日 7:00
- 効果: アップロード完了後すぐに公開設定 → 視聴者が必ずJST 7:00に見られる

## YouTube推薦アルゴリズム対策 (パッチB 2026-11-12)

### タイトルフォーマット改善
- 変更前: `prefix + parts + 日付` (例: `+2.3%｜エヌビディア決算｜11/12`)
- 変更後: `【日本語社名 決算】±%｜フック｜日付` (例: `【エヌビディア 決算】+9%｜フック｜11/12`)
- 根拠: ログインなし新規ブラウザのYouTubeレコメンドに拾われるには日本語社名＋決算＋%の組み合わせが必要

### 冒頭15秒ルール
- 動画最初の15秒で「銘柄名」「具体的な数字」「結論」をすべて言い切る
- 挨拶・前置きを排除し、逆三角形構成（結論→理由）を徹底
- 根拠: 視聴継続率がYouTube推薦アルゴリズムの最重要シグナル

### タグ強化
- 追加: 銘柄ティッカー（NVDA等）、日本語社名、「決算」
- 根拠: Googleの検索インデックスがタグも参照する

### 概要欄改善
- 冒頭に結論・数字・出典を配置
- `【毎朝7時更新】M月D日\n社名（決算）±%。lead` フォーマット
- 根拠: 検索結果プレビューの最初の2〜3行にキーワードが入ることが重要

## 今後の監視ポイント

1. **JST 7:00公開の確認**: 翌朝YouTube Studioで公開時刻を確認
2. **視聴継続率**: YouTube Analytics > 視聴者維持率 で冒頭15秒の離脱率を確認
3. **インプレッション**: レコメンド経由のインプレッション数を週次で確認
4. **タイムゾーン確認**: n8nサーバーのタイムゾーン設定を確認し、cronが正しく動作しているかログで検証

## 技術メモ

- n8nサーバーがJSTの場合: cronを `50 5 * * 1-6` に変更が必要
- n8nサーバーがUTCの場合: 現在の `50 20 * * 0-5` のままで正しい
- 要確認: `date` コマンドでサーバーのタイムゾーンを確認する
